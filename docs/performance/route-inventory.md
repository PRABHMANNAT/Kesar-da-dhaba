## Shared states

Desktop navigation; mobile overlay and keyboard focus; shared footer and lazy Google map; menu filters and dish details; legacy scroll timeline; shop products; honours dialogs; reviews and celebrity video/gallery rails; blog category filters and article links; home carousels, typed headings, video sound controls and back-to-top progress.

## Delivery

Existing local server has no compression or byte ranges. Controlled baseline and final runs use the same dedicated performance server with gzip and byte ranges, approximating static hosting. This is not a change to the user-owned local server. Fonts are local WOFF. Metadata is generated in each page module. See asset-inventory.json for every HTML media reference; CSS media references are also reviewed separately.
